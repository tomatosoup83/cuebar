# Cuebar 0.8.0 — Release Notes

Changes since 0.7.1 (`f29a994`). The three headline features are summarised in
[0.8.0.md](0.8.0.md).

## New

### Artist pages
- `artist ` is a scope: the list shows only artists, filtered by name. An empty
  field shows a random browse list.
- ⏎ on an artist row opens their page: a shuffled sample of their songs. Typing
  filters that artist's catalogue only. The page shows `Searching for songs from
  <artist>` in a status bar under the field.
- Artist rows appear in plain searches too. Their subtitle is the song count.
- Artists are grouped by **album artist**, falling back to the track artist, so a
  compilation stays under *Various Artists*. Feature credits (`feat.`) are not split.
- Esc, ⌫ on an empty field, or clicking the chip returns to the previous search.

### Extended album view
- ⌘⏎ on a library album, or **View Album** in ⌘K, opens the album's own view.
- The header shows the cover and a facts line (`year · genre · tracks · duration`).
  Parts without data are dropped rather than left blank.
- Tracks appear in their original running order with numbers (`1`, or `1-3` on
  multi-disc albums). Duration is shown on each row.
- Typing filters the album's tracks by title. Esc, ⌫ on an empty field, or the chip
  returns to the previous search.

### `cuebar://` URL scheme
- `cuebar://run?command=<anything you'd type>` runs a command headlessly.
  `cuebar://rebuild` re-indexes the library. Bare forms like `cuebar://pause` also
  work.
- Only exact command keywords are treated as commands, so `rebuilding my library`
  stays a song search.
- Library-only: a URL command never touches the iTunes catalogue. Commands that
  need the library wait up to 8 seconds if Cuebar is still starting.
- Results show as a toast. Window-only commands (settings, theme) report that they
  need the Cuebar window.
- Raycast extension in `raycast/`: **Run Cuebar Command**, plus **Pause**,
  **Play / Resume**, **Next Track**, **Previous Track** and **Toggle Shuffle**.

### Album Art v2 (opt-in)
- A third theme: **Album Art v2** builds the wash and accent from median-cut colour
  clusters instead of a single histogram bucket. It separates covers with several
  hues that the classic extraction merged.
- **Global Colours** (Settings, or `theme ` → Global Colours) mixes the whole cover
  into one colour with no gradient. Off by default.
- Available from Settings and by typing `theme `. Album Art v1 is unchanged.

### Quick actions (⌘K)
- **View Album** on library albums (shows ⌘↩).
- **Open Artist** on artist rows, in place of the song actions that don't apply to
  an artist.

## Improved

- **Search ranking:** `artist` / `artists` is a recognised keyword, and artist rows
  rank above songs and albums when you ask for them.
- **Returning from a detail view** restores the exact list, selection and scroll
  position. Browse lists are not reshuffled.
- **Follow the highlighted row** is available under both Album Art themes.
- **Theme filter** lists Album Art v2, and the Global Colours option appears only
  when v2 is selected.
- **Album facts:** the library index reads year and genre per track, and albums
  take their most common value. Album summaries fill in during the first launch
  after updating; no manual rebuild is needed.
- **Song-length display:** the now-playing card and album rows share one formatter,
  so times read the same everywhere.

## Notes for upgraders

- Your theme is not changed by this release.
- Launch once after updating so macOS registers the `cuebar://` scheme.
- The first launch re-indexes the library, which fills in album year and genre. The
  palette is usable during that time.
- Automation permission is unchanged. URL commands and the Raycast extension use
  Cuebar's own grant.

## Internal

- Palette extraction is split into `Algorithm` (classic / clustered) and
  `ClusterLayout` (gradient / global). `PaletteStyle` keys the palette cache, so the
  two Album Art themes and the Global Colours option don't overwrite each other.
- `AmbientPaletteCoordinator` re-resolves when the style changes, so switching
  theme or option updates colour immediately.
- Artist and album pages share `Ranking.rankWithin`, which matches on title only.
  Inside a single artist or album, the collection's own name would otherwise match
  every track.
- New debug environment variables for the artist and album views and the
  type-by-keystroke mode (`CUEBAR_OPEN_ARTIST`, `CUEBAR_OPEN_ALBUM`,
  `CUEBAR_SELECT_ALBUM`, `CUEBAR_EXTENDED`, `CUEBAR_ALBUM_BACK`,
  `CUEBAR_ARTIST_BACK`, `CUEBAR_TYPE_QUERY`, `CUEBAR_GLOBAL_COLOURS`). They are
  compiled out of release builds.
- Unit tests added for artist indexing, album facts, track numbering, the URL
  parser, headless command parsing, clustered extraction, the album view and the
  theme scope.
